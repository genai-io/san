快速开始

从安装到发出第一个提示词，只需几分钟。

1

安装

选择一种安装方式。更新时运行 san update；Homebrew 安装则使用 brew update && brew upgrade genai-io/san/san。

Homebrew

$ brew install genai-io/san/san

macOS / Linux

$ curl -fsSL https://raw.githubusercontent.com/genai-io/san/main/install.sh | bash

Windows (PowerShell)

> irm https://raw.githubusercontent.com/genai-io/san/main/install.ps1 | iex

更偏好 Go（需 1.26.9+）？go install github.com/genai-io/san/cmd/san@latest

2

启动并选择主题

运行 san 启动 San。首次启动时你需选择一个配色主题——选择后即可连接模型。

$ san
3

连接模型

输入 /models 打开模型设置，然后：

  1. 选择提供商，按提示添加 API 密钥。OpenAI 和 GitHub Copilot 也支持订阅账号登录。
  2. 等待提供商模型列表加载完成。
  3. 从模型列表中选择你想要的模型，开始编码。

随时通过 /models 切换提供商或模型。你的选择会保存到 ~/.san/providers.json。

准备就绪

输入 /help 探索斜杠命令，或深入了解文档。
