Getting Started

From install to your first prompt in a couple of minutes.

1

Install

Choose an installation method. To update, run san update, or brew update && brew upgrade genai-io/san/san for Homebrew installations.

Homebrew

$ brew install genai-io/san/san

macOS / Linux

$ curl -fsSL https://raw.githubusercontent.com/genai-io/san/main/install.sh | bash

Windows (PowerShell)

> irm https://raw.githubusercontent.com/genai-io/san/main/install.ps1 | iex

Prefer Go (1.26.9+)? go install github.com/genai-io/san/cmd/san@latest

2

Launch & pick a theme

Start San by running san. On first launch you'll pick a color theme — choose one, and you're ready to connect a model.

$ san
3

Connect a model

Type /models to open model settings, then:

  1. Choose a provider and add its API key when prompted. OpenAI and GitHub Copilot also support subscription sign-in.
  2. Wait for the provider's models to finish loading.
  3. Pick the model you want from the Model list, and start coding.

Switch providers or models anytime with /models. Your choice is saved to ~/.san/providers.json.

You're set

Explore slash commands with /help, or dive into the docs.
